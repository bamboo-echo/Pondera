↥ 一键搬运

在本机终端执行，使用现有 SSH 配置与 SFTP 通道。

推送到云端
pondera cloud push <session> --to <host> --remote-dir /srv/pondera/incoming
拉回本地继续
pondera cloud pull --from <host> --remote-dir /srv/pondera/out
实时旁观云端
pondera cloud watch <session> --url https://cloud:port --token <t>
